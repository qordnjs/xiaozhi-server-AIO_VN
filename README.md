# xiaozhi-server-AIO_VN
Đây là script tự động tải, cấu hình và chạy xiaozhi server gồm nhiều modules kết hợp dựa trên mã nguồn của https://github.com/xinnan-tech/xiaozhi-esp32-server.

1. Dùng ubuntu / debian gì cũng được, chỉ việc tải file setup.sh về, chmod +x setup.sh và cuối cùng gõ ./setup.sh và cài đặt.
2. Hoặc nhanh gọn lẹ 1 dòng lệnh duy nhất: sudo apt install wget -y && wget -O setup.sh "https://raw.githubusercontent.com/qordnjs/xiaozhi-server-AIO_VN/refs/heads/main/setup.sh" && chmod +x setup.sh && ./setup.sh && rm setup.sh
